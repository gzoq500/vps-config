{"code":400909, "message":"Your account has risk control restrictions. Please contact customer service."}

Content-Type: application/json
Body: {"code": "QB3238"}

The `api-platform_ph` parameter is a device fingerprint hash generated by MiMo's JavaScript.

## Root Causes

### 1. Datacenter IP
- Server IP: `43.167.12.204` (Tencent Cloud datacenter)
- Easily detected as non-residential via IP geolocation databases
- MiMo likely checks IP reputation/type before allowing referral binding

### 2. Headless Browser Fingerprint
- Playwright with `--no-sandbox` produces detectable markers:
  - `navigator.webdriver` = true (unless disabled)
  - Missing WebGL renderer info
  - Canvas fingerprint differs from real browsers
  - No audio context anomalies
  - Consistent viewport/timezone (not randomized)

### 3. New Account
- Account registered minutes before referral attempt
- No API usage, no balance, no history
- Low trust score

### 4. Multiple Accounts Same IP
- 10+ accounts registered from same server IP in one session
- IP flagged for bulk registration

### Playwright Stealth Args
```python
browser = await p.chromium.launch(
    headless=False,
    args=[
        '--no-sandbox',
        '--disable-blink-features=AutomationControlled',
        '--disable-features=IsolateOrigins,site-per-process',
        '--disable-site-isolation-trials',
    ]
)

# Override navigator.webdriver
await page.evaluate("Object.defineProperty(navigator, 'webdriver', {get: () => undefined})")
```
